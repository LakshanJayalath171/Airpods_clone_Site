AirPods Showcase Website

A modern, Apple-inspired AirPods showcase website built with React,
Tailwind CSS, and GSAP. The project focuses on immersive product
presentation, smooth scrolling, and polished animations to create an
engaging browsing experience.

✨ Features
- Modern, minimal UI inspired by Apple's product presentation
  style.
- GSAP animations for smooth, high-quality motion effects.
- ScrollTrigger interactions that animate elements as users scroll
  through the page.
- Responsive layout designed to work across desktop, tablet, and
  mobile screen sizes.
- Tailwind CSS styling for a consistent design system and
  efficient styling.
- Reusable React components to keep the interface organized and
  maintainable.
- Product-focused sections that highlight the AirPods design,
  features, and overall experience.

🎬 Animation Experience
Animation is a key part of this project. GSAP is used to create smooth
transitions and engaging motion throughout the page, while
ScrollTrigger connects selected animations to the user's scroll
position.

The goal is to make product sections feel dynamic without overwhelming
the content or making the experience difficult to navigate.

📱 Responsive Design
The layout is designed with responsive behavior in mind so that the
product presentation remains clear and usable on different screen sizes.
Review the page on desktop, tablet, and mobile devices when making
changes.
